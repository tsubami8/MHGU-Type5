# MHGU 操作类型 5 v1.2.0
适用版本为 **MHGU 1.4.0 + MHGU Recomp**。验证使用 Recomp 0.18.1 和 Build ID `FB08F1D20FD1204FE7070672777F869B`。压缩包包含 Forge 插件和构建源代码。

## 下载

从 [Releases](https://github.com/tsubami8/MHGU-Type5/releases) 下载 `MHGU-Type5-v1.2.0.zip`，解压后把 `MHGU Type 5 Prototype` 文件夹放进 Recomp 的 `mods` 目录。源码在本仓库 `source/`。

## 安装与启用

1. 退出 Recomp。用压缩包中的 `MHGU Type 5 Prototype` 文件夹替换旧版同名文件夹，或将它放进 Recomp 的 `mods` 文件夹。正式版沿用旧文件夹名，已有的加载顺序可以继续使用。
2. 在「选项 → 操作类型」里切换到类型 5，或打开「猎人笔记 → 操作类型」，向右切到第二页，选中类型 5 后确认。使用武器改键时，将「R摇杆的动作」设为类型 1。
3. 选择类型后，按游戏原本的流程保存。类型 5 的选择随当前猎人的 `system` 存档保存，完全退出 Recomp 后也能恢复。切回类型 1～4 后同样需要在游戏内保存。

Forge 的「类型 5 操作」区也提供启用开关。卸载时先退出游戏，再移走整个插件文件夹。

v0.2.1 修复了道具轮盘的输入挂接导致类型 5 初始化中止的问题。通过 Forge 保留已有挂接，也能同时加载外观装备与移动喝药的挂接。

v0.3.1 使类型 5 下弓的各处游戏逻辑都读取弓操作类型 1。组合键判定也统一使用标准肩键。锁定的选项在原生菜单置灰，操作类型循环切换时会刷新左下角说明。

v0.4.0 把地图缩放固定到 `L3`，把目标相机的选中和轮换固定到 `R3`。猎场右上角沿用原生目标准星，并显示右摇杆按键图标。进入类型 5 时，「L摇杆的动作」显示为置灰的类型 1。退出类型 5 后恢复原先保存的设定。

v0.4.1 在选项框显示类型 5 摘要，并在猎人笔记的「操作类型」里新增独立条目。右侧列表使用原生菜单的页码和翻页箭头，按方向键左右在两页之间切换。左侧用肩键翻阅四页详细说明。当前生效的类型显示在右侧的「当前操作类型」。

v1.0.0 将改键扩展到全部 14 种猎人武器。猎人笔记每次打开操作类型列表时从第一页开始，右下角继续显示当前生效的类型。

v1.1.2 使用 GU 1.4.0 存档中原 Switch 版未使用的 3DS 选项位保存类型 5。从早期版本升级后，请为当前猎人重新选择一次类型 5 并保存。本版无需额外的配置文件。

v1.2.0 对全部 14 种武器运行了台阶起跳和下落的输入回归测试。收刀时离开台阶后，按 `ZR` 会提交原生 `R+X+A`。实际动作由原生武器、风格和输入窗口决定。

> 最大程度还原从怪物猎人：世界起的作品的手柄操作，分离肩键及扳机键的功能，在猎人笔记-操作说明中查看详细说明。

## 当前操作

武器改键覆盖全部 14 种猎人武器。骑乘与固定弩台使用原生操作。

| 场景 | 类型 5 的输入 |
| --- | --- |
| 道具栏 | 长按 `L` 打开。选中怪物后，按「目标视角操作」设置使用 `L` 对准。 |
| 收刀移动 | 按住 `R` 并推动摇杆冲刺。可在收刀或动作恢复前按住，游戏允许冲刺时接上。 |
| 持武移动 | 按 `R` 提交一次原生短按 `Y`。继续按住 `R` 并推摇杆，收刀后接原生冲刺。 |
| 持武动作暂不可纳刀 | 继续按住 `R`，到站立或步行的纳刀窗口再提交原生 `Y`。提前松开 `R` 取消等待。 |
| 全部近战武器 | 持武时，原 `R` 的武器动作和组合技改用 `ZR`。收刀时按 `ZR` 提交原生 `R+X+A`。 |
| 收刀空中 | 从台阶跳出或下落时，按 `ZR` 提交原生 `R+X+A`。可用的空中拔刀动作取决于武器、风格和原生动作窗口。 |
| 喝药 | 喝药期间可按一次 `ZR` 预输入，正常结束后再提交拔刀组合键。 |
| 轻弩和重弩（已拔刀） | `ZR` 射击，`ZL` 短按切换开镜、长按快速瞄准。按住 `L` 打开弹药列表，用原生按键切换。蹲射时用原生架势指令进入蹲射，再按 `ZR` 开火。 |
| 轻弩和重弩（已收刀） | `ZR` 提交原生 `R+X+A`。 |
| 弓（已拔刀） | 按住 `ZR` 拉弦，松手传递原生发射输入。按住 `ZL` 瞄准，松手退出。`R` 以原生短按 `Y` 收刀，按住并推摇杆接冲刺。 |
| 弓（已收刀） | `ZR` 提交原生 `R+X+A`，触发近战拔刀。再次拉弦前先松开 `ZR`。 |
| 弓瓶 | 按住 `L`，用 `X/B` 切换瓶。原生 `X+A` 装瓶。 |
| 任务地图 | 按下左摇杆 `L3`，在全图与当前区域地图之间切换。 |
| 大型怪物目标 | 按下右摇杆 `R3`，在原生可选目标间轮换，循环中包含取消选中。 |

手动 `Y` 使用游戏原生收刀。类型 5 下，「L/R键的动作」「L摇杆的动作」「弩炮瞄准类型」「弓操作类型」「弓瞄准取消」置灰并锁定。

同时使用 CraftWheel 0.50 时，沿用先加载 CraftWheel、再加载类型 5 的顺序。轮盘打开和等待展开时，轮盘优先处理 `L3`、`R3`。松开当前按键后，下一次按下即可使用地图或目标相机。

## 实测范围

- v1.2.0 在竞技场台阶实测盾斧。原生 `R+X+A` 与类型 5 的 `ZR` 均从同一个台阶起跳状态触发同一个空中拔刀动作。

- v1.0.0 在隔离任务中逐一测试了新增的片手剑、长枪、太刀、斩斧、铳枪、双剑、狩猎笛和操虫棍。覆盖 `ZR` 拔刀及持武输入、`X/A` 动作，以及持续推摇杆时用 `R` 纳刀接冲刺。
- 类型 5 生效时重新打开猎人笔记，确认右侧回到 `1 / 2`，同时「当前操作类型」显示类型 5。向右翻页后即可查看类型 5 的详细说明。
- 勇气盾斧在持续推摇杆时按住 `R`，进入与原生短按 `Y` 相同的纳刀动作，随后进入冲刺。测试时存档本身启用了肩键交换。v0.1 的测试装备此前误记成大剑，实际为盾斧。
- GU 隔离任务中验证了勇气重弩直接按 `Y` 的原生行为。勇气奔跑中按 `Y` 未触发纳刀。类型 5 实测在奔跑中按住 `R`，到达自由态后才纳刀，随后接普通冲刺。重弩瞄准与射击也通过任务验证。
- 切入类型 5 前分别使用弓操作类型 1 和类型 2，测试中的近战拔刀、瞄准、拉弦和纳刀动作一致。收刀时按 `ZR` 的拔刀动作与持弓按 `A` 的近战动作使用同一挥击动作表。长按拔刀键也只触发一次。
- 菜单对照验证了类型 1 向左切到 5、类型 5 向右切回 1。进入类型 5 时，肩键和弓弩锁定项的名称和值均置灰，按 `A` 保持锁定并显示说明。
- 在双怪竞技场验证了 `R3` 轮换、原生准星与右摇杆图标，以及 `ZL` 不切换目标。将 L 摇杆原生选项设为类型 2 后，类型 5 中的 `L3` 仍可在全图和当前区域地图之间切换。
- 弓在行走时以 `R` 触发与短按 `Y` 相同的勇气纳刀，并在收刀后接冲刺。瞄准和拉弦相关动作沿用各自验证过的原生纳刀窗口。
- 独立输入测试覆盖 `L+X/B` 切瓶输入、`X+A` 装瓶组合及 `ZR` 释放。隔离任务没有可切换的弓瓶，箭矢发射也未稳定复现。
- 验证平台为 MHGU Recomp。猎场内已验证目标切换的按键图标和准星。骑乘与固定弩台改键仍停留在独立输入测试阶段，XX 和 Switch 原机版本仍待适配。

## 构建

在 `source` 目录使用 Python、支持 ARM 目标的 Clang 和 LLD 构建。工具参数可以指定可执行文件的完整路径。

```powershell
python build.py --clang clang --lld ld.lld --output type5.nro
```

也可使用 Zig 自带的工具链。

```powershell
python build.py --zig zig --output type5.nro
```

`controls_test.c` 可以与 `controls.c` 链接为宿主测试程序。测试入口 `type5_test` 返回零表示通过，非零表示失败断言的行号。
